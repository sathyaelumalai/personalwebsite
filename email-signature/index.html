Put it in Gmail

  1. Click Copy signature above (it copies the formatted version, images and all).
  2. In Gmail, open Settings → See all settings → General and scroll to Signature.
  3. Create a signature (or pick an existing one), click into the box, and paste (⌘V / Ctrl+V).
  4. Scroll down and click Save Changes. Send yourself a test email to confirm the images load.

Tip: if an image shows as broken, it usually means that file is not yet uploaded to /assets/ on the live site — see the status banner at the top of this page.
