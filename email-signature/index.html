Put it in Gmail

  1. Choose Company or Academic · DrPH above, pick your logo style, then click Copy signature.
  2. In Gmail, open Settings → See all settings → General and scroll to Signature.
  3. Click Create new, name it (e.g. "Aidar" or "Johns Hopkins"), click into the box, and paste (⌘V / Ctrl+V).
  4. Repeat for the second signature. Set your defaults for new emails and replies, then click Save Changes and send yourself a test.

Gmail stores multiple named signatures and lets you switch between them from the compose toolbar. If an image ever shows as broken, that file is not reachable under /assets/ on the live site — see the status banner up top.
